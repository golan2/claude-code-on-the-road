# GitLab with glab

`glab` (the GitLab CLI) is installed and logged in. Call it with an exec request. It needs the full repo path as `host/owner/namespace/repo` in `--repo`, for example `imugit.imubit.com/imubit-dlpc/task-force/model-analysis-service`. If you don't know it, find the checkout under `~/git`, run `git remote -v` there with exec, and read it from the output. Do not guess it and do not ask Izik.
